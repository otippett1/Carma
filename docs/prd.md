# Carma PRD

## Overview
Carma is a mobile-first marketplace and community for car enthusiasts to buy/sell parts, follow vendors, and discover nearby events.

## Target Users
- Enthusiasts looking for parts and community
- Private sellers and professional vendors
- Event organizers

## Core Features (MVP)
- Marketplace: browse/search parts, view listings
- Vendor and user profiles: follow vendors/users
- Events: discover nearby events
- Auth: email/password via Supabase
- Notifications: basic in-app notifications

## Non-Goals (MVP)
- Real-time chat
- Complex payments/escrow

## Success Metrics
- DAU, listings created, follows, event RSVPs

## Tech Stack
- Client: React + Vite (PWA-ready)
- API: Node + Express
- DB/Auth/Storage: Supabase
