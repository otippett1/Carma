# Task List – Carma Prototype 1

Each task is based on the Analyst’s user stories and includes a clear completion definition.

Marketplace

T1. Implement Search Filters

Story: Search for parts using make, model, year, and trim.

Done: Search form filters results accurately; validation prevents empty searches; “No parts found” message displays when applicable.

T2. Add Used/New Toggle

Story: Switch between used and new listings.

Done: Toggle filter updates the product list instantly; UI shows current filter.

T3. Display Seller Ratings and Reviews

Story: View seller ratings to determine trustworthiness.

Done: Vendor cards show average rating, total reviews, and clickable detailed review list.

T4. Report Listing Feature

Story: Report misleading or incorrect listings.

Done: Report form saves reason to database; success confirmation displays; reported listing flagged for admin review.

T5. Verified Vendor Profiles

Story: Vendors can create verified business profiles.

Done: Vendor dashboard allows editing details; verified vendors show a badge; unverified vendors cannot access advanced tools.

T6. Follow Vendor System

Story: Follow vendors to receive updates.

Done: Follow button toggles state; followed vendors’ updates appear in personalized feed.

Community

T7. Community Feed

Story: Browse community posts such as builds, tutorials, and tips.

Done: Feed shows recent posts with images or videos; like and comment features functional.

T8. Join Groups

Story: Join themed groups (e.g., JDM, Muscle, Euro).

Done: Users can join or leave groups; feed filters based on joined groups.

T9. How-To Q&A Module

Story: Post questions with media for community feedback.

Done: Q&A posts include text and up to three images; answers can be marked as “best.”

Events

T10. Discover Nearby Events

Story: View car meets within a certain radius.

Done: Users can set a radius filter; list updates dynamically; event details link to location.

T11. Create Event Form

Story: Event organizers can create events with details.

Done: Form validates input; event saves to database; visible in event listings.

T12. Vendor Event Registration

Story: Vendors register to table at upcoming events.

Done: Vendor profile links to event form; confirmation message shown upon submission.

Profiles

T13. Edit User Profile

Story: Add profile photo, bio, and car information.

Done: Users can update and save information; changes appear on profile instantly.

T14. Authentication and Session Management

Story: Enable login and signup to secure user data.

Done: Supabase authentication works; protected routes limit access for logged-in users only.
